# proxy

Прокси-сервисы на Node.js + Telegram-бот для продажи подписок на них.

## `web-proxy/` — личный прокси для повседневного использования

HTTP(S) forward-proxy + SOCKS5 в одном процессе, с обязательной
авторизацией по логину/паролю. Без внешних зависимостей. Для браузера,
мессенджеров, curl, торрент-клиентов и т.п. См. `web-proxy/README.md`.

## `telegram-bot/` — бот для продажи подписок на web-proxy

Telegram-бот с кнопками «Личный кабинет», «Управление подписками» и
«Купить подписку»: реальная оплата (Telegram Stars или платёжный
провайдер), автоматическая выдача логина/пароля и включение/отключение
доступа к `web-proxy` по статусу подписки. Плюс HTTP API для `android-app/`.
См. `telegram-bot/README.md`.

## `android-app/` — Android-клиент, связанный с Telegram

Kotlin/Compose-приложение: вход через Telegram (без пароля, по
диплинку/коду), личный кабинет, управление подписками, покупка (оплата —
в Telegram). VPN-туннель — заготовка на следующий шаг, подробности и
ограничения (нет сборки/теста в этой среде) — в `android-app/README.md`.

## `game-proxy/` — UDP-прокси для игрового сервера SA-MP/open.mp

Прозрачно пересылает UDP-трафик игроков на реальный игровой сервер,
скрывая его настоящий IP (снижает риск DDoS). Без внешних зависимостей.
См. `game-proxy/README.md`.
